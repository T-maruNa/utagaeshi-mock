# SNS画像ジェネレータ

うたがえし公式SNS用の「今日の景色」画像を作ります。

1枚の画像に入るのは、**今日の景色**と**問いかけ**だけです。
うたがえし側の返しは載せません（理由は `.claude/agents/uta-post.md`）。

出力は2サイズ。

| ファイル名 | サイズ | 用途 |
|---|---|---|
| `TT_◯◯.png` | 1080×1920 | TikTok・Instagram |
| `X_◯◯.png` | 1600×900 | X（タイムラインで切れない比率） |

## 作りかた

`gen.js` の下のほうにある `DAYS` を書き換えて実行するだけです。

```js
const DAYS = [
{ file:'01_雨やどり', palette:'cool',
  scene:'急に雨が降ってきて、<br>軒下で止むのを待っている。' },
];
```

- `file` … 出力ファイル名につく名前
- `palette` … 配色（下の表）
- `scene` … 画像に入れる今日の景色。`<br>` で改行位置を決める

```
node gen.js
```

`out/` に画像が出ます。

## 配色

景色ごとに変えること。全部同じ色だと並んだときに見分けがつきません。

| 名前 | 合う景色 |
|---|---|
| `warm` | 夕方、朝の光、あたたかい話 |
| `fresh` | 風、緑、小道、外を歩く話 |
| `cool` | 雨、曇り、涼しさ |
| `quiet` | 静かな話、落ち着いた話 |
| `night` | 夜、室内、暗い時間 |

## 書体

以下が入っている前提です。入っていないと別の書体で出ます。

- Shippori Mincho … 景色の本文
- Zen Kaku Gothic New … ラベル・問いかけ
- Zen Maru Gothic … 下の「うたがえし」

無い場合は Google Fonts から取って `~/.local/share/fonts/` に置き、
`fc-cache -f` を実行してください。

## 動かない場合

- `Cannot find module 'playwright'` → `NODE_PATH=/opt/node22/lib/node_modules node gen.js`
- ブラウザが見つからない → `chromium.launch` の `executablePath` を環境に合わせる

## 景色を書くときの注意

**言い切らないこと。** 景色の中で感想まで書くと、読んだ人の書く余地がなくなります。

- ○ 洗い物をしながら、窓に自分が映っている。
- × 洗い物をしながら、窓に映る自分を見て一日の疲れを思った。
