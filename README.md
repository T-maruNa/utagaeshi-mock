# うたがえし — UIモック（Phase 1）

> 昔のうたに、今の言葉で返す。

「うたがえし」MVP仕様 **Phase 1：UIモック** の成果物です。
毎日1首の古典短歌をお題に、AIのやさしい解説をヒントにして、今の自分の言葉で返す投稿サービス —— その画面イメージを、HTML/CSS だけで再現したスマホ向けの静的モックです。

バックエンド・DB・認証・AI連携はまだ含みません（Phase 2 以降）。すべてダミーデータで動きます。

## 画面一覧

| ファイル | 画面 | 内容 |
| --- | --- | --- |
| `index.html` | ホーム（今日のうた） | **今日のうたが主役**（返せるのは今日のうただけ）。今日のうた（日付・短歌・作者・出典・このうた好き数・返し数・届いた反応数）→このうた好き／返しを全部見る→投稿導線（単独行）→AI読み解きのヒント（別行・初期は閉じた状態）→「このうたに届いた返し」（新着／よく届いた・補助文「このうたに、みんなはこう返しました。」・**うたがえしAIの返し**を自然に混在）→軽い導線（← 昨日のうたを見る／明日ひらくうたの予告カード／過去のうた／返しタイムライン）。ランキング表現（1位・トップ・今日いちばん等）は使わない |
| `posts.html` | 返しタイムライン | 今日＋過去のお題への返しが日付をまたいで流れるフィード。各カードに元の短歌（冒頭・日付・作者）と「このうたへの返しを全部見る」導線。新着／人気の並び替え |
| `user.html` | 他ユーザーの返し帳 | その人の返しを読むだけのページ（DM・コメント・フォロー・外部SNSなし）。返し本文・元のうた情報・届いた反応 |
| `poem-detail.html` | お題詳細 | 1首への返しを全部読むページ。短歌・作者・出典・日付・AI読み解き・熱量指標・「このうた好き」・返し一覧（うたがえしAIの返しを含む）・前の日／次の日移動・過去のうた一覧導線 |
| `archive.html` | 過去のうた | 過去のお題を一覧（日付・冒頭・作者・出典・返し数・反応数・このうた好き数）。人気のうたへの導線 |
| `popular-poems.html` | 人気のうた | このうた好き・返し・届いた反応でうたを並べる |
| `ranking.html` | ランキング | 今日いちばん響いた返し（1位）と2位以下、順位ルールの注記。誰でも閲覧可 |
| `post-detail.html` | 返し詳細 | どの古典短歌に、この人がどう返したか。返し本文・投稿者・リアクション・日時＋元のお題・AIヒント・各導線 |
| `mypage.html` | 自分の返し帳 | ログイン必須。**主役は返しカード**（プロフィールは1行だけの控えめな添え書きに縮小、今日のお題・AIに読んでもらうは無し）。自分の返しが本の1ページのように残るカードを1枚ずつ大きく表示（今日＋過去の返し計4件を前後にめくれる。返し本文だけ縦書き、日付・元のうたリンク・届いた反応・前後移動は横書き）。アカウント設定／ログアウトは下部に小さな下線リンクとして添える |

## 閲覧開放型のUX方針

**読むだけなら誰でもOK。** 投稿を強制せず、まず読んで「返してみたいな」と思ってもらう構成です。ログインが必要なのは行動のときだけ。

- **ログインが必要**：返す／リアクション／返し帳を見る／AIに読んでもらう
- **ログイン不要（誰でも閲覧可）**：今日の短歌・作者出典・AI読み解き・このうたに届いた返し一覧・ランキング

未ログインでこれらの行動をタップすると、画面下からログイン誘導シートが出ます。

## 動くところ（デモ用の簡易挙動 / `assets/app.js`）

- **ログインゲート**：未ログインで「返す・リアクション」を押すと「◯◯するにはログインが必要です」の誘導シートを表示。返し帳はログイン必須（未ログイン時は誘導）。状態は `localStorage` で保持
  - デモのログイン：`login.html` のボタン、または誘導シートの「ログイン / 新規登録」
  - デモのログアウト：返し帳（マイページ）の「ログアウト」
- **投稿バー＋モーダル（X風）**：ホーム上部の固定投稿バー（または「自分の言葉で返す」）をタップすると投稿モーダルが開く。お題の短歌を再掲しつつ入力。ログイン時のみ開き、未ログインはログイン誘導。返すとフィード先頭に自分の返しが差し込まれ「返しました」トースト表示
- **文字数 10〜200字**：カウント表示、10字未満は「あとN字」で送信不可、200字超は「N字オーバー」を警告表示して送信不可
- 返しへのリアクション3種（わかる／刺さった／好き）のトグル（ログイン時のみ）と、短歌への「このうた好き」（返しreactionとは別・1ユーザー1回・ログイン必須）。DM・コメント・外部SNS導線は持たず、距離を保ったリアクション中心
- 返しタイムライン：各カードから元の短歌ページ（`poem-detail.html`）へ、前の日／次の日で別日のお題へ回遊。`archive.html`（過去のうた）・`popular-poems.html`（人気のうた）で「毎日更新される言葉のアーカイブ」として回遊
- 未ログインで投稿導線を押すとログイン誘導モーダル（「返すにはログインが必要です。」＋「ログインする／あとで」）
- 各返しをタップすると返し詳細ページへ
- 「読み解きのヒント」を折りたたみで開閉（初期は閉じた状態）
- うたがえしAIの返しが、みんなの返し一覧にカードとして自然に参加（模範解答ではなく場を温める返し・ラベルと注記つき・ランキング対象外）
- みんなの返しの「新着 / 人気」並び替え
- 「AIに読んでもらう」ボタンでダミー感想を表示（返し帳・将来枠）
- 返し帳の「返し本文」だけを縦書きで表示（1文字ずつ要素化して積む方式。ブラウザ／フォント依存の文字重なりを避けるため、CSSのwriting-modeではなくこの実装にしている）。カードは「← 前の返し／次の返し →」で前後にめくれ、左右スワイプにも対応
- 下部ナビの現在地ハイライト

## デザイン方針（仕様 §13 準拠）

- 原文が主役。AIは控えめ。
- 余白多め・静か・でも古臭くない。
- 和風に寄せすぎない（筆文字・金箔・古典学習アプリ感を避ける）。
- 短歌原文は明朝系、UIはゴシック系。アクセントは藍を思わせる控えめな一色。
- スマホ幅（最大480px）を基準。PCでは中央にカードとして表示。
- ライト／ダークモード対応（`prefers-color-scheme`）。

## ローカルで見る

```bash
# 任意の静的サーバーで
python3 -m http.server 8000
# → http://localhost:8000/
```

`index.html` をブラウザで直接開いてもOKです。

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. Branch に `claude/utagaeshi-mvp-spec-0orgow`（または `main` にマージ後は `main`）、フォルダは `/ (root)` を選択
4. 数十秒後、`https://t-maruna.github.io/utagaeshi-mock/` で表示されます

## ダミーデータについて

- お題の短歌は **持統天皇「春過ぎて 夏来にけらし…」（百人一首・二番）** など、著作権切れの古典短歌のみを使用しています。
- AI読み解き・うたがえしAIの返し・みんなの返し・リアクション数はすべてサンプルです。AIは現代語訳の「正解」を示すものではなく、読み解きの補助です。
