# うたがえし — UIモック（景色ファースト）

> 千年前の歌人と、同じ景色を見る。

「うたがえし」の画面イメージを、HTML/CSS/素のJSだけで再現したスマホ向けの静的モックです。
バックエンド・DB・認証・AI連携は含みません。すべてダミーの内容で動きます。

実装は [utagaeshi](https://github.com/t-maruna/utagaeshi)。

## いまのモックは「景色ファースト」

以前のモックは**百人一首のお題に返す**サービスの形でした（`index.html` が今日のうた、
`posts.html` が返しタイムライン、`popular-poems.html` が人気のうた……）。
実装側の全体刷新で、サービスの構造そのものが次のように変わったので、モックも作り直しています。

```
旧： 百人一首を見る → 現代sceneを見る → 自分が投稿する → 他人の投稿を見る

新： 今日の景色に出会う
     → なんとなく一言残したくなる
     → 自分の言葉が一枚になる
     → 同じ景色から出た他人の言葉をめくる
     → その中に千年前の人の言葉まで混ざっている
     → 後で返し帳を開くと、その日の景色まで思い出す
```

百人一首は「今日の教材」ではなく、**同じ景色について何か残した千年前の一人**として混ざります。
AIによる読み解きの解説は廃止しました。

設計の根拠（なぜそうするか）は実装側の
[REDESIGN.md](https://github.com/t-maruna/utagaeshi/blob/main/REDESIGN.md) が正本です。
このモックは、その決定が画面としてどう見えるかを持ちます。

## 見かた

クローンして `index.html` をブラウザで開くだけです（ビルド不要）。
横幅 390〜430px（iPhone相当）で見てください。

```bash
git clone https://github.com/t-maruna/utagaeshi-mock.git
cd utagaeshi-mock
open index.html      # もしくは python3 -m http.server で配信
```

モックの日付は **2026年10月8日（木）** 固定です。10月・9月の景色画像と、その日の言葉が入っています。

## 画面一覧

| ファイル | 実装のroute | 役割 |
| --- | --- | --- |
| `index.html` | `/` | **今日**。1枚のデッキで今日を見せる。景色 → 自分 → 千年前と他の人。投稿欄と、デッキの目次になる2列グリッド |
| `day.html` | `/poems/[id]` | **その日の景色**。古典を振り返る画面ではなく、その日の自分を拾い直す画面。作りはホームと同じで、投稿欄が無く、抽選も上限もない |
| `scenes.html` | `/poems` | **これまでの景色**。ひらいた日が月ごとに並ぶ。主役は景色の文で、写真は56pxのサムネイル。日付の移動はここに集約する |
| `mypage.html` | `/mypage` | **返し帳**。ホームと並ぶ主役。大きなカードを1枚ずつめくり、月ごとの目次から開く。`残した言葉` / `心に残った言葉` の2タブ |
| `mypage-list.html` | `/mypage/list` | **言葉を整える**。改行を直す・消す。返し帳の中に操作を置かないための分け先 |
| `user.html` | `/users/[userId]` | **○○さんの残した言葉**。「返し帳」とは呼ばない。デッキ5枚＋全件の目次 |
| `profile.html` | `/profile` | **プロフィール**。自分が他人からどう見えるかを確認・編集する。編集はこの画面の中で行う |
| `account.html` | `/account` | **アカウント設定**。メールアドレス・パスワード・ログアウト・退会だけ |
| `login.html` / `signup.html` | `/login` `/signup` | ログイン／新規登録。体験の主役ではないので、パレットとタイポだけ追従する |
| `intro.html` | `/intro` | **はじめての方へ**。ここだけ visual-card を使わない小さな本（全4ページ）。ホームから送る導線は持たない |
| `legal.html` | `/terms` `/privacy` | 規約・ポリシーの見え方だけ。条文の正本は実装側 |

### 削除した画面

| ファイル | 理由 |
| --- | --- |
| `poem-detail.html` | `day.html`（その日の景色）へ。1首の詳細ではなく、その日を拾い直す画面になった |
| `archive.html` | `scenes.html`（これまでの景色）へ。「百人一首一覧」から「過去の景色一覧」へ転換 |
| `posts.html` | **廃止**。全日横断のタイムラインを作ると一気にSNS化して、「この景色から、この言葉が生まれた」という核が消える |
| `post-detail.html` | **廃止**。言葉を単品で見たい導線が無かった。全文はカードのその場で開き、シェアはカード下の操作行にある |
| `popular-poems.html` | **廃止**。うたを人気順に並べる画面は持たない |
| `liked.html` | 返し帳の「心に残った言葉」タブと同じものなので、2箇所に持たない |

## 部品

全画面が同じ部品でできています。クラス名は実装の部品名と1対1です。

| 見た目 | クラス | 実装 |
| --- | --- | --- |
| 景色 × 言葉 の一枚 | `.vcard`（`--scene` / `--mine` / `--poem` / `--other`） | `VisualCard` |
| めくるデッキ | `.deck` `.deck-ctrl` `.deck-open-row` | `CardDeck` / `PersonDeck` |
| 2列グリッドの小カード | `.word` | `WordChip` |
| 一覧・目次の1行 | `.index-row` / `.toc-row` | `IndexRow` / 返し帳の目次 |
| 月の折りたたみ | `.toc-month` | `MonthAccordion` |
| 投稿欄 | `.compose-card` | `SceneComposer` |

**めくる操作は全画面で同じ**です。←→ と左右スワイプ（45px以上・縦に大きい動きは無視）でめくれ、
目次の行を押してもページ遷移せず、上のカードが切り替わって、開いている札が目次でも光ります。

## ファイル構成

```
assets/
  styles.css     実装の src/app/globals.css をそのまま持ってきたもの（トークン・基礎）
  ui-next.css    実装の src/app/ui-next.css をそのまま持ってきたもの（部品）
  mock.css       モックだけに要る差分（素の<img>のサムネイル・hidden の扱い）
  app.js         画面の挙動。実装のReact部品と同じ触り心地にするためだけのもの
  scenes/        景色の画像（10月・9月の各8枚）。実装の public/scenes と同じもの
```

### CSSの正本について

刷新前は「モックのHTML/CSSを実装が写す」一方向でしたが、景色ファーストへの作り直しは
実装側が先行したため、**このモックのCSSは実装の2枚をそのまま持ってきています**。
どちらかを直したら、もう一方にも同じ差分を入れてください。値がずれると、実装側の
サイズ回帰テスト（`home-mock-css.test.ts` / `book-css.test.ts`）が意味を失います。

モックだけに要る差分は `mock.css` に置き、コピーの2枚は触りません。
