# うたがえし — UIモック（Phase 1）

> 昔のうたに、今の言葉で返す。

「うたがえし」MVP仕様 **Phase 1：UIモック** の成果物です。
毎日1首の古典短歌をお題に、AIのやさしい解説をヒントにして、今の自分の言葉で返す投稿サービス —— その画面イメージを、HTML/CSS だけで再現したスマホ向けの静的モックです。

バックエンド・DB・認証・AI連携はまだ含みません（Phase 2 以降）。すべてダミーデータで動きます。

## 画面一覧

| ファイル | 画面 | 内容 |
| --- | --- | --- |
| `index.html` | 今日のお題 | 短歌原文（主役）＋作者・出典、AI解説、AI投稿例、今日のトップ投稿、みんなへの導線 |
| `post.html` | 投稿作成 | お題の再掲、AI解説の折りたたみ、例文タップで下書き、文字数カウント（140字）、投稿ボタン |
| `posts.html` | 投稿一覧 | みんなの返し、リアクション、新着／人気の並び替え |
| `ranking.html` | ランキング | 今日のトップ投稿、2位以下、順位ルールの注記 |
| `mypage.html` | マイページ | プロフィール、返した数・もらった反応・連続日数、投稿履歴 |
| `login.html` | ログイン／新規登録 | Googleログイン推奨＋メール認証、規約リンク |

## 動くところ（デモ用の簡易挙動 / `assets/app.js`）

- リアクションボタンのトグル（押す＝＋1／もう一度＝取り消し）
- 投稿作成の文字数カウントと送信ボタンの有効化（空・140字超は無効）
- AI投稿例をタップすると入力欄に下書きとして入る
- 投稿一覧の「新着 / 人気」並び替え
- 下部ナビの現在地ハイライト

## デザイン方針（仕様 §13 準拠）

- 原文が主役。AIは控えめ。
- 余白多め・静か・でも古臭くない。
- 和風に寄せすぎない（筆文字・金箔・古典学習アプリ感を避ける）。
- 短歌原文は明朝系、UIはゴシック系。アクセントは藍を思わせる控えめな一色。
- スマホ幅（最大480px）を基準。PCでは中央にカードとして表示。
- ライト／ダークモード対応（`prefers-color-scheme`）。

## ローカルで見る

```bash
# 任意の静的サーバーで
python3 -m http.server 8000
# → http://localhost:8000/
```

`index.html` をブラウザで直接開いてもOKです。

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. Branch に `claude/utagaeshi-mvp-spec-0orgow`（または `main` にマージ後は `main`）、フォルダは `/ (root)` を選択
4. 数十秒後、`https://t-maruna.github.io/utagaeshi-mock/` で表示されます

## ダミーデータについて

- お題の短歌は **持統天皇「春過ぎて 夏来にけらし…」（百人一首・二番）** など、著作権切れの古典短歌のみを使用しています。
- AI解説・投稿例・ユーザー投稿・リアクション数はすべてサンプルです。現代語訳の「正解」を示すものではありません。
