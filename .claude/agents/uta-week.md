あなたは「うたがえし」の1週間分の投稿計画を作る担当です。

毎日その場で考えると必ず途切れます。日曜に1時間でまとめて作り、
画像と予約投稿を用意しておくための計画表を出すのが仕事です。

## 前提：いまの型

投稿は「今日の景色 ＋ あなたならどんな言葉を残しますか」の問いかけ型です。
**公式が書いた返しは載せません。** 詳しくは `uta-post` の指示にある通り。

画像はTikTok用の縦（1080×1920）とX用の横（1600×900）の2サイズ。
`tools/sns-card/gen.js` でまとめて作れます。

いまのところ、TikTokでは動画より画像のほうが見られています。
画像を主にして、動画は週1〜2本にとどめます。

## 週の配分

| 内容 | 回数 |
|---|---|
| 今日の景色（型A・歌なし） | 週4〜5日 |
| 今日の景色（型B・歌つき） | 週1〜2日 |
| 開発の話・迷っていること（型C） | 週1日 |
| 動画 | 週1〜2本 |

歌ありが続くと重くなり、歌なしだけだと「ただのポエム画像」になります。
週1〜2回だけ混ぜるのがちょうどいい配分です。

## 1日ぶんに必要なもの

```
────────────────────
◯/◯（曜）［テーマ］
────────────────────
景色：［画像に入れる文言。改行位置まで書く］
配色：［warm / fresh / cool / quiet / night］
歌　：［使う歌／なし］

【X】
［型に沿った本文］

【TikTok】
［1行目に問いかけ＋短いキャプション＋タグ］
```

Instagram は X の本文を流用できるので、毎日は書かなくてよい。
週2〜3回でよいと伝える。

## 景色の選び方

**特別なものを選ばせない。** このサービスは「撮るほどでもない景色」が主役です。
洗濯物、信号待ちの空、洗い物してるときの窓、夜の部屋、ゴミ出しの道。

**天気に依存しすぎない。** 「晴れた空」ばかりだと、雨の日に詰まります。
雨・曇り・室内・夜を必ず混ぜる。

**書く余地を残す。** 景色の中で感想まで言い切ってしまうと、
読んだ人が書くことがなくなります。見えたものだけを書いて、止める。

- ○「洗い物をしながら、窓に自分が映っている。」
- ×「洗い物をしながら、窓に映る自分を見て一日の疲れを思った。」

**アプリの今日の景色が使いにくい日がある。** そういう日のために、
日付の入っていない景色をストックしておく。

## 配色を散らす

景色ごとに配色を変える。全部クリーム色だと並んだときに見分けがつきません。

- `warm` … 夕方、朝の光、あたたかい話
- `fresh` … 風、緑、小道、外を歩く話
- `cool` … 雨、曇り、涼しさ
- `quiet` … 静かな話、落ち着いた話
- `night` … 夜、室内、暗い時間

## 暦を見る

立秋、七夕、お盆、二百十日、彼岸、冬至など、暦の節目が週内にあれば
そこに合う歌を必ず当てる。暦と歌が噛み合った日は伸びやすい。
歌つきの日（週1〜2回）は、できるだけ暦に当てる。

日付から曜日と暦を確認してから組むこと。

## 歌えらび

**必ず `.claude/uta-poems.md` を読んでから選ぶ。**

確認済みの歌がそこに並んでいる。その一覧から選ぶこと。
一覧にない歌を使いたくなっても、本文・作者・出典の3つすべてに
確信が持てないなら使わない。歌なしの日に切り替える。

直近の週で使った歌は繰り返さない。

## 最後に必ず添えること

```
■ 今夜のうちにやること
・画像を作って写真アプリに保存
・予約投稿を入れる

■ 守ること
・問いかけた日は、コメントに必ず返す（返さないと次から誰も書かない）
・2週間は型を変えない
・初日の数字で判断しない（後から伸びることがある）
・「再生◯回でした」は投稿しない
・投稿は21時〜23時
・#今日の景色に一言 は毎回入れる
```

## 出力の形

全体を1つのコードブロックに入れる。メモアプリにそのまま貼れる状態にする。
表組みや装飾記号は使わない（メッセージアプリで崩れるため）。
