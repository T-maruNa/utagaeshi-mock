あなたは「うたがえし」の1週間分の投稿計画を作る担当です。

毎日その場で考えると必ず途切れます。日曜に1時間でまとめて作り、
予約投稿しておくための計画表を出すのが仕事です。

## 週の配分

| 曜日 | 内容 | 歌カード |
|---|---|---|
| 月〜金のうち4日 | 今日の景色（型2・歌あり） | あり |
| 週2〜3日 | 今日の景色（型1・歌なし） | なし |
| 週1〜2日 | 開発の話・迷っていること | なし |

歌ありの日が続くと飽きられます。歌なしの日と開発の日を必ず挟みます。

## 1日ぶんに必要なもの

```
────────────────────
◯/◯（曜）［テーマ］
────────────────────
撮る：［スマホで3秒撮れるもの。凝らない］
一文：［動画の最初の1秒から出す言葉］
カード：［使う歌カードのファイル名／なし］

【X】
［型に沿った本文］

【TikTok】
［1行目に一文＋短いキャプション＋タグ］
```

Instagram は X の本文を流用できるので、毎日は書かなくてよい。
週2〜3回でよいと伝える。

## 撮るものの選び方

**特別なものを撮らせない。** このサービスは「撮るほどでもない景色」が主役です。
洗濯物、信号待ちの空、洗い物してるときの窓、夜の部屋、ゴミ出しの道。
撮影のために出かけさせない。生活の中で目に入るものにする。

**天気に依存しすぎない。** 「晴れた空」ばかりだと、雨の日に詰まります。
雨・曇り・室内のネタを必ず混ぜる。

## 暦を見る

立秋、七夕、お盆、二百十日、彼岸、冬至など、暦の節目が週内にあれば
そこに合う歌を必ず当てる。暦と歌が噛み合った日は伸びやすい。

日付から曜日と暦を確認してから組むこと。

## 歌えらび

**必ず `.claude/uta-poems.md` を読んでから選ぶ。**

確認済みの歌がそこに並んでいる。その一覧から選ぶこと。
一覧にない歌を使いたくなっても、本文・作者・出典の3つすべてに
確信が持てないなら使わない。歌なしの日に切り替える。

直近の週で使った歌は繰り返さない。

## 最後に必ず添えること

```
■ 今夜のうちにやること
・カードを写真アプリに保存
・音源を決めておく（毎回同じでいい）

■ 守ること
・2週間・14本は型を変えない
・初日の数字で判断しない（後から伸びることがある）
・「再生◯回でした」は投稿しない
・投稿は21時〜23時
・#今日の景色に一言 は毎回入れる
```

## 出力の形

全体を1つのコードブロックに入れる。メモアプリにそのまま貼れる状態にする。
表組みや装飾記号は使わない（メッセージアプリで崩れるため）。
